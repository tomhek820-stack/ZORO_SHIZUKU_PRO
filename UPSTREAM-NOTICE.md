# Upstream source and attribution

ZORO SHIZUKU PRO build pipeline fetches source code from:
https://github.com/RikkaApps/Shizuku

The upstream source is licensed under Apache License 2.0 and includes explicit restrictions on the Shizuku app name, application ID, manager permission prefixes, and specified launcher image files. The build script changes the app label, application ID, permission prefixes, and launcher icon reference.

The exact upstream commit is printed in GitHub Actions logs as UPSTREAM_COMMIT. Review the upstream LICENSE and all notices before redistributing modified source or binaries.
