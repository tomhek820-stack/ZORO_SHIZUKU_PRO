# ZORO SHIZUKU PRO — مشروع بناء مستقل

هذا المستودع يحتوي على إعداد بناء يجلب شيفرة Shizuku مفتوحة المصدر من مستودعها الرسمي، ثم يطبق تعديلات الهوية الخاصة بـ ZORO ويطلب من GitHub Actions بناء APK.

> **الحالة بوضوح:** لم يتم بناء APK أو اختباره على هاتف داخل هذه الجلسة. اختبار البناء الفعلي يحصل في GitHub Actions بعد تشغيل workflow. يعتمد البناء على توفر المستودع الأصلي والإنترنت وقت التشغيل.

## ما الذي يحاول البناء إنتاجه؟
- مدير Shizuku المعدّل باسم التطبيق `ZORO SHIZUKU PRO`.
- معرف تطبيق مستقل: `com.zoro.shizukupro`.
- تعديل بادئات أذونات المدير لتناسب الهوية الجديدة.
- أيقونة متجهية جديدة.
- مصدر Shizuku وخدماته الأصلية، بما فيها تشغيل الخدمة عبر Wireless debugging على الإصدارات المدعومة، وبدء الخدمة عبر root عند توفره.

## طريقة البناء
1. افتح تبويب **Actions** في المستودع.
2. اختر **Build ZORO SHIZUKU PRO** ثم **Run workflow**.
3. اترك `upstream_ref` على `master` أو أدخل tag/commit صالحًا من المصدر الرسمي.
4. بعد نجاح التشغيل، نزّل artifact باسم `ZORO-SHIZUKU-PRO-DEBUG-APK`.

## تنبيهات توافق مهمة
- ADB اللاسلكي على Android 11+ يتطلب تفعيل خيارات المطور وWireless debugging وإكمال الاقتران وفق آلية Android.
- وضع root يتطلب جهازًا مروّتًا ووجود أداة `su` مع موافقة المستخدم.
- خدمة Shizuku في وضع ADB تحتاج عادة إلى تشغيلها مجددًا بعد إعادة تشغيل الهاتف.
- تغيير application ID قد يمنع بعض التطبيقات من اكتشاف الخدمة تلقائيًا إذا كانت تعتمد على معرف الحزمة الأصلي. لذلك لا يمكن ضمان التوافق الكامل مع كل تطبيقات Shizuku قبل اختبار APK على الجهاز والتطبيقات المستهدفة.
- لا توزّع APK قبل مراجعة الترخيص والإشعارات في المصدر الذي تم جلبه. احتفظ بملف LICENSE وإشعارات حقوق النشر.
